# Link Service

Консольное приложение для сокращения ссылок и их последующего открытия.  
Проект реализует простой сервис коротких ссылок с авторизацией пользователя по UUID, ограничением по времени жизни и количеству переходов.

Данные хранятся **в памяти приложения** и сериализуются в файл при завершении работы.

---

## Возможности

### Пользователи
- Автоматическая регистрация пользователя при первом использовании
- Авторизация по UUID
- Выход из текущей сессии

Каждая короткая ссылка привязывается к конкретному пользователю.  
Открывать короткую ссылку может **только её владелец**.

---

### Работа со ссылками

- Сокращение длинных HTTP/HTTPS ссылок
- Генерация короткой ссылки вида `clck.ru/XXXXXXXX`
- Открытие оригинальной ссылки в браузере по короткой
- Ограничения:
  - срок жизни ссылки
  - лимит переходов

После превышения лимита или истечения времени ссылка автоматически удаляется.

---

## Основные команды

Команды вводятся напрямую в консоль.

- `help` — список доступных команд  
- `login <uuid>` — вход по UUID  
- `logout` — выход из текущей сессии  
- `exit` / `quit` — завершение программы  
- `http(s)://...` — сократить длинную ссылку  
- `clck.ru/XXXXXXXX` — открыть короткую ссылку  

---

## Логика работы

### Регистрация
Если пользователь не авторизован и вводит длинную ссылку,  
для него автоматически создаётся UUID, который необходимо сохранить.

### Сокращение ссылки
- Вводится длинная ссылка
- Хэш формируется на основе:
  - исходного URL
  - UUID пользователя
- Используется SHA-256 + кодирование в Base62
- Итоговый код — 8 символов

### Открытие ссылки
- Проверяется:
  - авторизация пользователя
  - принадлежность ссылки пользователю
  - срок действия
  - лимит переходов
- При успехе ссылка открывается в браузере

---

## Ограничения ссылок

Параметры задаются в конфигурации:

- Срок жизни ссылки — **24 часа**
- Максимум переходов — **10**

После нарушения любого условия ссылка удаляется из хранилища.

## Стек и требования

- **Java 17+**
- **Maven**
- Apache Commons Codec (SHA-256)
- Работа с браузером через `java.awt.Desktop`

---

## Структура проекта

- `config/` — параметры хранения и ограничений  
- `console/` — CLI и обработка пользовательских команд  
- `data/` — модель данных и in-memory хранилище  
- `linking/` — логика генерации коротких ссылок  
- `Main` — точка входа в приложение  

---

## Хранение данных

- Все данные хранятся в `Map` в памяти
- При выходе из приложения данные сериализуются в файл
- При старте приложения данные загружаются в память приложения из файла
